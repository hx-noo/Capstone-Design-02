# 전기차 배터리 화재 예방을 위한 머신러닝 기반 예측 모델 비교 연구

## 1. 프로젝트 개요

### 목적

- 배터리 실험 데이터를 활용해 배터리 특성과 주변 온도 사이의 관계를 회귀모델로 분석
- MLP·XGBoost·LightGBM의 예측 성능을 비교하고 하이퍼파라미터 탐색으로 모델 개선
- 배터리 안전 관리에 활용할 수 있는 예측 모델의 가능성과 한계 탐색

### 진행 기간

**[2025.03 ~ 2025.12]**

### 공동 수행 범위

- **학부생 2명 공동 수행:** 공개 데이터 수집·전처리, 회귀모델 학습·평가, 파생변수 설계 및 하이퍼파라미터 탐색

## 2. 프로젝트 핵심

- **공개 데이터 활용:** 배터리 실험 데이터 **7,565건**을 활용해 저항·용량 등 배터리 특성 분석
- **데이터 전처리·변수 확장:** 결측값 처리·범주형 인코딩 및 저항 합·비율·로그 파생변수 생성
- **회귀모델 비교:** MLP·XGBoost·LightGBM **3종**을 MAE·RMSE·R²로 평가
- **모델 최적화:** **5-fold 교차검증**과 RandomizedSearchCV로 XGBoost·LightGBM의 파라미터 탐색
- **입력 변수 확장:** 용량·저항 기반 **SOC·SOH 대리 지표** 추가

### 연구 진행 흐름

| 단계 | 수행 내용 |
| --- | --- |
| 기본 모델 비교·논문 제출 | 배터리 데이터 전처리 및 MLP·XGBoost·LightGBM 비교, 입력 변수 확장·모델 최적화의 필요성 정리 |
| 교차검증·튜닝 | XGBoost·LightGBM에 5-fold 교차검증과 RandomizedSearchCV를 적용하고 기본 모델 대비 R² 비교 |
| 입력 변수 확장·최종 발표 | 저항 합·비율·로그 변환 및 용량·저항 기반 SOC·SOH 대리 지표 추가 |

## 3. 주요 결과

| 구분 | 주요 결과 |
| --- | --- |
| 데이터 분할 | 학습 **6,052건** · 테스트 **1,513건** |
| 기본 모델 비교 | XGBoost **MAE 5.99 · RMSE 8.92 · R² 0.37** — 논문 보고값 |
| XGBoost 튜닝 | R² **0.3749 → 0.3785** — 중간발표 결과 |
| LightGBM 튜닝 | R² **0.3647 → 0.3755** — 중간발표 결과 |
| 후속 입력 변수 확장 | 저항 파생변수와 용량·저항 기반 **SOC·SOH 대리 지표** 추가 |

예측 대상은 **주변 온도(`ambient_temperature`)**입니다. 배터리 화재 예방을 연구 배경으로 삼아 온도 예측을 수행했습니다.

## 4. 회고

- **아쉬운 점:** 모델 비교·튜닝 후에도 중간발표의 최고 R²는 **0.3785**로, 충분한 설명력을 확보하지 못했습니다.
- **발표 피드백:** 포스터 발표에서 **입력 변수에 발화 관련 요인이 충분한지 검토해 보라**는 조언을 받았습니다.
- **개선 과정:** 교차검증·튜닝과 함께 입력 변수 구성을 재검토하고, 후속 실험에서 **저항 파생변수·SOC/SOH 대리 지표**를 추가했습니다.
- **배운 점:** 데이터 양이나 튜닝만으로 성능의 한계를 단정하기보다, **예측 목적에 맞는 입력 정보**를 먼저 살펴봐야 한다고 느꼈습니다.
- **다음 목표:** 다양한 운용 조건의 데이터와 실제 상태 지표를 확보해, **변수 추가 전후의 성능을 동일한 조건에서 비교**해 보고 싶습니다.
