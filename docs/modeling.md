# 분석·모델링 및 결과

[프로젝트 요약으로 돌아가기](../README.md)

## 1. 분석 목적

배터리 실험 특성으로 **주변 온도(`ambient_temperature`)**를 예측하는 회귀모델을 비교했습니다.

## 2. 모델 구성

| 모델 | 구현·설정 |
| --- | --- |
| MLP | TensorFlow·Keras의 Sequential, Dense·Dropout 계층으로 구성 |
| XGBoost | `XGBRegressor`, 기본 비교에서 `n_estimators=100` |
| LightGBM | `LGBMRegressor`, 기본 비교에서 `n_estimators=100` |

먼저 세 모델의 기본 성능을 비교해 논문으로 정리했습니다. 이후 XGBoost·LightGBM의 교차검증·튜닝을 진행하고, 최종발표에서는 저항 파생변수와 SOC·SOH 대리 지표로 입력 정보를 확장했습니다.

## 3. 평가 방법

학습 80%·테스트 20%로 분할하고 다음 지표로 모델을 비교했습니다. 후속 튜닝에서는 학습 데이터에 5-fold 교차검증을 적용했습니다.

| 지표 | 확인 내용 | 비교 기준 |
| --- | --- | --- |
| MAE | 실제값과 예측값의 평균 절대 오차 | 낮을수록 좋음 |
| RMSE | 큰 예측 오차에 더 민감한 오차 지표 | 낮을수록 좋음 |
| R² | 목표 변수의 변동에 대한 모델 설명력 | 높을수록 좋음 |

## 4. 모델 비교 결과

다음은 **연구 논문에 보고한 평가값**입니다.

| 모델 | MAE | RMSE | R² |
| --- | --- | --- | --- |
| MLP | 7.75 | 53.64 | −21.59 |
| **XGBoost** | **5.99** | **8.92** | **0.37** |
| LightGBM | 6.07 | 8.99 | 0.36 |

- **XGBoost:** 세 지표에서 가장 좋은 값을 보였으며, LightGBM과 유사한 성능
- **LightGBM:** XGBoost에 근접한 오차와 설명력
- **MLP:** 큰 예측 오차와 음수 R²로 일반화 성능의 한계 확인

## 5. 개선 과정

### 1. 논문 제출 후 교차검증·하이퍼파라미터 탐색

논문에서는 낮은 설명력과 입력 정보의 한계를 논의하고, SOC·SOH를 포함한 변수 확장과 모델 최적화를 개선 방향으로 제시했습니다. 이후 캡스톤에서는 먼저 XGBoost·LightGBM의 하이퍼파라미터 탐색과 교차검증을 구체화했습니다.

#### 탐색 방법

- **검증:** `KFold(n_splits=5, shuffle=True)`
- **탐색:** `RandomizedSearchCV(n_iter=30)`
- **선택 기준:** 교차검증 **R²**
- **평가:** 탐색으로 선택한 모델의 테스트 MAE·RMSE·R²를 계산하고, 기본 모델 대비 R² 변화 비교

#### 주요 탐색 범위

| 모델 | 파라미터 | 탐색값 |
| --- | --- | --- |
| 공통 | `n_estimators` | 200, 300, 400, 600, 800 |
| 공통 | `learning_rate` | 0.03, 0.05, 0.07, 0.1 |
| XGBoost | `max_depth` | 3, 4, 5, 6, 7 |
| XGBoost | `min_child_weight` | 1, 2, 4, 6 |
| XGBoost | `subsample` | 0.8, 1.0 |
| XGBoost | `colsample_bytree` | 0.7, 0.9, 1.0 |
| LightGBM | `num_leaves` | 31, 47, 63, 95 |
| LightGBM | `max_depth` | −1, 6, 8, 10 |
| LightGBM | `min_data_in_leaf` | 10, 20, 40, 80 |

이외에도 XGBoost의 `gamma`·`reg_lambda`, LightGBM의 `feature_fraction`·`bagging_fraction`·`bagging_freq`·`min_gain_to_split`·`reg_lambda`를 탐색했습니다.

### 2. 튜닝 결과

중간발표에 제시한 기본 모델과 튜닝 모델의 테스트 R² 비교입니다.

| 모델 | 기본 R² | 튜닝 후 R² | 변화량 |
| --- | --- | --- | --- |
| **XGBoost** | 0.3749 | **0.3785** | +0.0036 |
| LightGBM | 0.3647 | 0.3755 | +0.0108 |

- **튜닝 모델 비교:** XGBoost가 R² **0.3785**로 가장 높은 값을 기록
- **튜닝 효과:** LightGBM은 +0.0108로 더 큰 개선 폭을 보였고, XGBoost는 +0.0036 개선
- **비교 결론:** XGBoost와 LightGBM이 MLP보다 좋은 예측 성능을 보였으며, 튜닝 후에도 두 모델의 설명력 차이는 작았음

### 3. 후속 입력 변수 확장

포스터 발표에서는 입력 변수(X)에 발화 관련 요인이 충분히 포함되어 있는지 검토할 필요가 있다는 피드백을 받았습니다. 이 피드백과 논문의 개선 제안을 계기로, 모델 설정뿐 아니라 입력 정보의 적합성도 재검토했습니다.

최종발표에서는 논문의 개선 제안을 바탕으로 다음 작업을 진행했습니다.

- **저항 파생변수:** `Re + Rct`, `Re / Rct`, `log(Re)`, `log(Rct)`를 생성해 입력 정보 확장
- **상태 대리 지표:** 용량 비율 기반 `SOC_proxy`와 저항 합의 역비율 기반 `SOH_proxy` 추가
- **전처리 통합:** 수치형 중앙값 대체·범주형 최빈값 대체·One-Hot 인코딩을 Pipeline과 ColumnTransformer로 구성

추가한 변수는 기존 용량·저항 값에서 계산한 배터리 특성 지표입니다. 실제 발화 원인을 측정한 변수나 화재 위험 예측에 대한 검증 결과와는 구분합니다.

중간발표의 튜닝 수치와 최종발표의 변수 확장 내용은 **서로 다른 실험 단계**로 정리했습니다.

## 6. 한계

- **제한적인 설명력:** 최상위 모델도 R²가 약 0.38 수준이므로, 다양한 배터리 상태와 운용 환경을 설명하기 위한 입력 정보 보완 필요
- **예측 대상의 범위:** 주변 온도 회귀 결과이며, 실제 화재 발생이나 배터리 교체 여부의 예측 성능을 평가한 결과와 구분
- **추가 검증:** 실제 주행·충방전 조건을 포함한 데이터 확장과 배터리 상태 변수의 타당성 검증 필요
- **원인 구분:** 데이터 규모·입력 정보·모델 설정의 영향을 분리해 평가하지 않았으므로, 성능의 한계를 특정 원인 하나로 확정하기 어려움
