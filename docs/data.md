# 데이터 수집·전처리

[프로젝트 요약으로 돌아가기](../README.md)

## 1. 데이터 개요

### 데이터 출처

- **공개 배터리 실험 데이터:** Kaggle 등 공개 데이터에서 배터리 특성 데이터를 수집해 활용
- **모델 학습 데이터:** 배터리 저항·용량·실험 유형·주변 온도 등을 포함한 가공 CSV(`metadata.csv`)
- **활용 규모:** 총 **7,565건**

### 입력 변수(X)와 예측 대상(Y)

| 구분 | 주요 컬럼 | 내용 |
| --- | --- | --- |
| X | `Re` | 전해질 저항 |
| X | `Rct` | 전하 전달 저항 |
| X | `Capacity` | 배터리 용량 |
| X | `type` | 충전·방전 등 실험 유형 |
| Y | `ambient_temperature` | 실험의 주변 온도 |

기본 모델은 주변 온도를 제외한 특성으로 온도를 예측했습니다. 논문 제출 후 캡스톤을 이어가며 교차검증·튜닝을 진행했고, 최종발표에서는 저항 관련 파생변수와 용량·저항 기반 대리 지표를 추가했습니다.

## 2. 데이터 전처리

### 1. 불필요한 컬럼 제거

- 기본 학습 코드에서 `start_time`, `battery_id`, `test_id`, `uid`, `filename` 제외
- `ambient_temperature`를 목표 변수로 분리하고 나머지 특성을 입력 변수로 구성

### 2. 자료형 변환·결측값 처리

- `Re`, `Rct`, `Capacity`를 숫자형으로 변환
- 숫자로 변환할 수 없는 값은 결측값으로 처리
- 기본 실험에서는 저항·용량의 결측값을 해당 컬럼의 **평균값**으로 대체
- 확장 실험에서는 무한대를 결측값으로 변환하고, 수치형은 **중앙값**, 범주형은 **최빈값**으로 대체

### 3. 범주형 인코딩·스케일링

| 구분 | 처리 방법 |
| --- | --- |
| 기본 실험 | `type`에 LabelEncoder 적용, MinMaxScaler로 입력값 정규화 |
| 확장 실험 | 수치형·범주형을 분리해 Pipeline과 ColumnTransformer로 처리 |
| 확장 실험의 범주형 변수 | OneHotEncoder(`handle_unknown="ignore"`) 적용 |

확장 실험에서는 전처리기를 학습 데이터에 적합하고, 같은 전처리기로 학습·테스트 데이터를 변환했습니다.

## 3. 파생변수

### 저항 특성

| 파생변수 | 계산 | 활용 목적 |
| --- | --- | --- |
| `res_sum` | `Re + Rct` | 두 저항의 합 반영 |
| `res_ratio` | `Re / Rct` | 저항 간 상대적 비율 반영 |
| `log_Re` | `log(Re)` | 전해질 저항의 로그 변환 |
| `log_Rct` | `log(Rct)` | 전하 전달 저항의 로그 변환 |

로그 계산과 나눗셈을 위해 저항값의 하한을 `1e-6`으로 제한했습니다.

### 용량·저항 기반 대리 지표

논문에서 제안한 SOC·SOH 입력 변수 확장 방향을 바탕으로, 최종발표에서는 다음 대리 지표를 계산했습니다.

- **`SOC_proxy`:** 최대 용량 대비 현재 `Capacity`의 비율을 백분율로 계산하고 0~100으로 제한
- **`SOH_proxy`:** 최소 저항 합 대비 현재 저항 합의 역비율을 백분율로 계산하고 0~120으로 제한

두 변수는 용량·저항으로 만든 **대리 지표**이며, 별도 장비로 직접 측정한 SOC·SOH 값과 구분합니다.

## 4. 학습·테스트 분할

| 구분 | 비율 | 데이터 수 |
| --- | --- | --- |
| 학습 | 80% | **6,052건** |
| 테스트 | 20% | **1,513건** |
| 전체 | 100% | **7,565건** |

- `train_test_split(test_size=0.2)`로 학습·테스트 데이터 분리
- 튜닝은 학습 데이터의 **5-fold 교차검증**으로 진행하고, 테스트 데이터에서 최종 예측 성능 평가
